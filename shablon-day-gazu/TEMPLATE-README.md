# Шаблон сайта «Дай газу»

Готовый одностраничник для автосервиса под названием **«Дай газу»**. Чистая
статика — никакого npm и сборки, файлы открываются как есть. Сделан копией
шаблона автосервиса ([Shablon_Avtoservice](../Shablon_Avtoservice)), он же
сделан из сайта Auto Region 161. Структура, блоки и калькулятор — те же,
поменяно только название.

Главная мысль сайта: **цену называем до начала работ, и в конце она не
вырастет** — потому что мы ищем причину, а не меняем детали наугад.

Контакты, адрес и реквизиты — заглушки (`+7 (000) 000-00-00`, «ул. Примерная,
1»), фотографий нет: везде плашки с подписью, какой кадр нужен. Под конкретного
клиента заполняется по таблице ниже.

## Как посмотреть

Windows — двойной клик по «Запустить сайт (Windows).bat».
macOS — двойной клик по «Запустить сайт.command».

Или руками:

```bash
cd Shablon_Day_Gazu/site && python3 -m http.server 8907
```

Дальше открыть http://localhost:8907 . Порт лучше каждый раз новый — браузер
жёстко кэширует старую версию.

## Где стоит название

«Дай газу» прописано в четырёх местах — при переименовании править все:

| Что | Где |
|---|---|
| Название в шапке и коротко (`ДГ`) для логотипа | `site/content.js`, блок `brand` |
| Заголовок страницы для поиска | `site/content.js`, блок `meta` + `site/index.html` |
| Название организации в подвале | `site/config.js`, блок `legal` |
| Текст для выключенного JavaScript | `site/index.html`, блок `noscript` |

## Как сделать вариант под конкретный сервис

**Копировать папку целиком** (`Site_<название>`), править копию. Сам шаблон
остаётся чистым.

Дальше по файлам:

| Что меняем | Где |
|---|---|
| Название, телефон, адрес, реквизиты, ссылки на Яндекс.Карты и Авито | `site/config.js` |
| Все тексты: заголовки, услуги, отзывы, вопросы, гарантия | `site/content.js` |
| Цвет и шрифт | `site/theme.css` |
| Заголовок вкладки и описание для поиска | `site/index.html` |
| Цифры калькулятора: нормо-час, интервал ТО | `site/config.js`, блок `calc` |

Цвет меняется **только** в `theme.css` и сразу всем блоком переменных
«Акцент», а не одной `--accent`.

## Фотографии

В шаблоне фотографий нет вообще — везде стоят плашки с подписью, какой кадр
туда нужен. Это удобно вдвойне: сайт можно показывать как есть, а клиент по
плашкам сразу понимает, что от него нужно прислать.

Чтобы поставить фото, в `content.js` у нужной плашки добавить `src`:

```js
{ src: 'img/boks.jpg', need: 'Ремонтный бокс с подъёмниками', w: 1600, h: 1069 }
```

Файл положить в `site/img/`. Фото пережимать в JPEG примерно 1400–1600 px по
длинной стороне, качество 80 — иначе страница тормозит на телефоне. Обрезать
и «улучшать» фильтрами не надо, вёрстка подстраивается под кадр сама.

## Чего нельзя делать

- Никаких `blur`, `backdrop-filter` и бесконечных анимаций — сайт должен
  летать на телефоне.
- `white-space: nowrap` на длинной строке ломает мобильную вёрстку: страница
  становится шире экрана и всё съезжает.
- В комментариях CSS не должно быть `*/` внутри текста — это молча обрывает
  комментарий и ломает следующую переменную.
- Блок мобильных правил в конце `blocks.css` должен оставаться последним.

## Что проверять перед отправкой клиенту

Телефон и десктоп, обе ширины. Пройти все три вкладки в блоке «что мы делаем»,
подвигать ползунки калькулятора, раскрыть все вопросы, проверить кнопки
WhatsApp и ссылку на Яндекс.Карты.
