## TC-03. Тариф «TestQuest Коробка (on-premise)» — модель «Магистры»
**Предусловие:** выбран тариф «Коробка».
**Шаги:** ввести 100 лицензий, поочерёдно срок 12 / 24 / 36 мес.

## TC-05. Срок лицензии — пороги скидок
**Предусловие:** тариф «Облако», 100 лицензий.
**Шаги:** ввести срок 3 / 5 / 6 / 12 мес.
**ОР:** < 6 мес — скидки нет (3 мес → **62 634 ₽**, 5 мес — линейно от 1 мес);

**Автотест:** `tests/test_licenses_term.py`

## TC-06. Модули — коэффициент по группам и по «Мессенджеру»
**Предусловие:** тариф «Облако», 100 лиц., 12 мес.
**Шаги:** отмечать модули: ключевой (напр. «Конструктор процессов»),
дополнительный («Задачи»), «Мессенджер»; смотреть поле «К-т по модулям» и «Всего».
**ОР:** ключевой модуль +0,2; дополнительный +0,1; «Мессенджер» +0,3;
«К-т по модулям» = `1 + Σ надбавок`, поле только для чтения (считается автоматически).
Все три вместе → коэффициент 1,6; цена лицензий растёт пропорционально коэффициенту.
**Автотест:** `tests/test_modules.py`

## TC-07. Модуль «в подарок»
**Предусловие:** выбран хотя бы один необязательный модуль.
**Шаги:** нажать кнопку-подарок у модуля.
**ОР:** в смете напротив модуля — «в подарок» (цена 0), коэффициент по модулям
**не увеличивается** на надбавку подарочного модуля. Кнопка-подарок недоступна
для обязательных (базовых) модулей.
**Автотест:** `tests/test_modules.py`

## TC-09. Time&Material — резерв часов
**Предусловие:** вкладка «T&M».
**Шаги:** оставить 100 чч, затем ввести 50 чч, затем 0.
**ОР:** 100 чч → **585 000 ₽** без НДС; 50 чч → 292 500 ₽; 0 → 0 ₽.

**Автотест:** `tests/test_implementation_tm.py`

## TC-10. ИТОГО — агрегатор сметы
**Предусловие:** тариф «Облако», 300 лиц., 12 мес, «Мессенджер», скидка 10 %,
внедрение: ТЗ + приёмочные тесты.
**Шаги:** посмотреть строки «Лицензии», «Скидка 10 %», «Внедрение», «Всего».
**ОР:** `Всего = лицензии_со_скидкой + внедрение_с_НДС`. Внедрение
(117 000 + 58 500) с НДС 5 % = 184 275 ₽. Строка «Скидка N %» показывается только
при скидке > 0. Блок T&M — отдельно, со своим «Всего».
**Автотест:** `tests/test_totals.py`

## TC-11. Выгрузка сметы в Excel
**Предусловие:** заполнены компания, проект, лицензии, срок; выбран тариф.
**Шаги:** нажать «Выгрузить смету в Excel».
**ОР:** скачивается `.xlsx` (OOXML) по шаблону КП; имя файла по маске
`<дата>, КП по реализации проекта <проект> на платформе Бублики для компании <компания>, ООО Технологии защиты.xlsx`;
подставленные из сметы значения окрашены зелёным (`ARGB FF00B050`), поля для ручной
проверки — красным. Если не выбран ни один тариф — ошибка «Выберите тариф для выгрузки сметы».
**Автотест:** `tests/test_excel_export.py` (шаблон декодируется из `kp-template-base64.js`
и проверяется как валидный ZIP/OOXML: `[Content_Types].xml`, `xl/workbook.xml`, листы, медиа).

## TC-12. Валидация обязательных полей
**Предусловие:** разделы «Счета» / «Акты» / «Договоры»; калькулятор.
**Шаги:** нажать «Сформировать …» с пустыми обязательными полями; в калькуляторе
ввести 0 лицензий и 0 месяцев (Облако).
**ОР:**
- Счёт: требуются номер, дата, ИНН (10 или 12 цифр), юр. название; поля подсвечиваются
  классом `param-input--invalid`, форма прокручивается к первой ошибке.
- Акт: номер, дата, реквизиты заказчика.
- Договор: номер, дата, размер и стоимость пакета лицензий.
- Калькулятор (Облако): при 0 лицензий или 0 мес смета = 0 ₽; поля чисел принимают
  только цифры.
**Автотест:** `tests/test_validation.py`
