# Зеленый дом — сайт центра ГБО

Копия шаблона [Shablon_CentrGBO](../Shablon_CentrGBO) под конкретного
клиента. Сам шаблон не трогаем — правим только эту папку.

Запуск: двойной клик по «Запустить сайт (Windows).bat» (или
`.command` на маке). Откроется http://localhost:8080 .

## Что уже подставлено

- Название организации — «Зеленый дом» (`config.js`, `content.js`,
  заголовок вкладки в `index.html`).

## Что осталось заполнить

| Что | Где | Сейчас стоит |
|---|---|---|
| Телефон, WhatsApp, Telegram | `site/config.js` → `contacts` | `+7 (000) 000-00-00` |
| Ссылки на Яндекс.Карты (организация, отзывы, маршрут) | `site/config.js` → `yandex` | заглушка `yandex.ru/maps/` |
| Авито и отзывы на Авито | `site/config.js` → `links` | пусто |
| ОГРНИП, ИНН, ОКПО | `site/config.js` → `legal` | нули |
| График работы (по нему горит индикатор в шапке) | `site/config.js` → `schedule` | пн–сб 09:00–20:00 |
| Счётчик переведённых машин | `site/config.js` → `counter` | база 5000 |
| Тексты: услуги, отзывы, вопросы, гарантия | `site/content.js` | текст шаблона |
| Цвет и шрифт | `site/theme.css` | акцент шаблона |
| Описание для поиска (`<meta name="description">`) | `site/index.html` | текст шаблона |

Фотографий нет — везде плашки с подписью, какой кадр нужен. Чтобы
поставить фото, в `content.js` у плашки добавить `src: 'img/имя.jpg'`
и положить файл в `site/img/` (JPEG 1400–1600 px по длинной стороне,
качество 80).

Остальные правила — в [TEMPLATE-README.md](TEMPLATE-README.md):
чего нельзя делать с CSS и что проверять перед отправкой клиенту.
