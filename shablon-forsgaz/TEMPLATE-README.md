# Сайт Force-Gaz (ГБО, карбюраторы, ремонт)

Одностраничник для сервиса **Force-Gaz**, пос. Образцово, г.о. Щёлково.
Чистая статика — никакого npm и сборки, файлы открываются как есть.
Основа — шаблон автосервиса ([Shablon_Avtoservice](../Shablon_Avtoservice)),
он же сделан из сайта Auto Region 161.

Главная мысль сайта: **цену называем до начала работ, и в конце она не
вырастет** — потому что мы ищем причину, а не меняем детали наугад.

## Как посмотреть

Windows — двойной клик по «Запустить сайт (Windows).bat».
macOS — двойной клик по «Запустить сайт.command».

Или руками:

```bash
cd Shablon_FORSGAZ/site && python3 -m http.server 8906
```

Дальше открыть http://localhost:8906 . Порт лучше каждый раз новый — браузер
жёстко кэширует старую версию.

## Что ещё нужно от клиента

- **Фотографии.** Их на сайте нет вообще — везде плашки с подписью, какой
  кадр нужен. Клиент по плашкам сразу видит, что прислать.
- **Счётчик на первом экране** («5 021 машин отремонтировано») — число из
  шаблона, не настоящее. Реальную цифру ставить в `config.js` → `counter.base`,
  либо убрать блок совсем.
- **Реквизиты** (ОГРНИП, ИНН, ОКПО) — в `config.js` → `legal`. Пока пусто,
  и строка с ними в подвале не выводится.
- **Политика конфиденциальности** — появится в подвале, когда в
  `content.js` → `footer` заполнить `privacyLabel` и `privacyHref`.

Чтобы поставить фото, в `content.js` у нужной плашки добавить `src`:

```js
{ src: 'img/boks.jpg', need: 'Ремонтный бокс с подъёмниками', w: 1600, h: 1069 }
```

Файл положить в `site/img/`. Пережимать в JPEG примерно 1400–1600 px по
длинной стороне, качество 80 — иначе страница тормозит на телефоне.

## Ссылки

Соцсетей у сервиса нет, поэтому все ссылки ведут только на телефон,
мессенджеры по тому же номеру и карточку на Яндекс.Картах:
звонок (`tel:`), WhatsApp (`wa.me`), Telegram (`t.me/+7969…`),
карточка, отзывы и маршрут на Яндекс.Картах. Мёртвых ссылок (`href="#"`)
на странице нет — это проверяется глазами и через консоль.

## Оформление

Тема бело-синяя: белый фон, синий акцент `#2f6fed`. Цвет правится **только**
в `theme.css` и сразу всем блоком переменных «Акцент», а не одной `--accent`.
Первый экран остаётся тёмным всегда — он лежит на своей сцене, и текст там
задан светлым жёстко.

## Чего нельзя делать

- Никаких `blur`, `backdrop-filter` и бесконечных анимаций — сайт должен
  летать на телефоне.
- `white-space: nowrap` на длинной строке ломает мобильную вёрстку. В меню
  шапки он стоит осознанно: пункты короткие, а ниже 1080 px меню другое.
- В комментариях CSS не должно быть `*/` внутри текста — это молча обрывает
  комментарий и ломает следующую переменную.
- Блок мобильных правил в конце `blocks.css` должен оставаться последним.

## Что проверять перед отправкой клиенту

Телефон и десктоп, обе ширины. Пройти все три вкладки в блоке «что мы делаем»,
подвигать ползунки калькулятора, раскрыть все вопросы, проверить кнопки
WhatsApp, Telegram и ссылку на Яндекс.Карты.
