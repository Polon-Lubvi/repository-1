# repository-1

Резервная копия работ, выполненных через Claude Code. По подпапке на проект.

## Проекты
- `testquest-kalkulyator-smet/` — комплект автотестов «Калькулятора смет» TestQuest (тест-кейсы + run-tests.sh/bat).
- `shablon-centr-gbo/` — шаблон одностраничника для центра установки и обслуживания ГБО (статика, без сборки), сделан на основе шаблона автосервиса.
- `site-centr-gbo-spb/` — клиентский сайт «Центр ГБО» (Санкт-Петербург, Смоляная ул., 10Ж) на основе шаблона выше: сине-белая палитра, реальные контакты/отзывы/график с Яндекс.Карт.
- `shablon-day-gazu/` — сайт «Дай газу» (Москва, ул. Академика Скрябина, 19с1): на основе шаблона автосервиса, белая тема с красным акцентом, реальные данные с Яндекс.Карт (телефон, график, рейтинг 4,3, девять пятизвёздочных отзывов, живая карта), все кнопки связи ведут на звонок.
