# QA Freelance Monitor — Telegram-бот

Круглосуточно проверяет фриланс-биржи и присылает в Telegram новые заказы,
связанные с QA и тестированием.

| Биржа | Как читается |
|---|---|
| FL.ru | RSS всех заказов |
| Freelancehunt | RSS всех заказов |
| Kwork | поиск по «тестирование», «тестировщик», «QA», «автотесты» |
| Freelance.ru | лента заданий |
| Weblancer | лента заказов |
| Freelancer.com | публичный API, поиск по qa / manual / software testing |
| PeoplePerHour | категории Software Testing и Technology & Programming |
| Guru | лента Programming & Development и общая лента |
| Telegram | 12 каналов, список ниже |

Хабр Фриланс закрыт, RSS Upwork отключён, поэтому их в списке нет.

### Telegram-каналы

Каналы читаются через публичное веб-превью `t.me/s/<канал>`. Бот не нужно добавлять в каналы,
подписываться на них тоже не нужно.

Профильные QA-каналы: присылаются все вакансии, рекламные посты и статьи отсеиваются.
- [@forallqa](https://t.me/forallqa) — Job for QA
- [@ingamejob_qa](https://t.me/ingamejob_qa) — QA и тестирование в геймдеве
- [@qa_jobs_rabota](https://t.me/qa_jobs_rabota) — вакансии QA Engineer / тестировщикам
- [@qa_rabota](https://t.me/qa_rabota) — QA_Jobs

Общие IT- и фриланс-каналы: присылаются только посты, у которых QA-слово стоит в заголовке.
- [@jobforjunior](https://t.me/jobforjunior), [@Remoteit](https://t.me/Remoteit), [@geekjobs](https://t.me/geekjobs),
  [@habr_career](https://t.me/habr_career), [@vakansii_it](https://t.me/vakansii_it),
  [@FreeWorkFeed](https://t.me/FreeWorkFeed), [@Getitrussia](https://t.me/Getitrussia), [@remote_w0rk](https://t.me/remote_w0rk)

Каналы добавляются и убираются в списках `TG_QA_CHANNELS` и `TG_GENERAL_CHANNELS` в `bot.py`.
Канал подойдёт, только если у него открыто веб-превью: страница `https://t.me/s/<канал>` показывает посты.

Новый источник при первом запуске запоминается молча, чтобы не прислать пачку старых постов.
Одна и та же вакансия, опубликованная в нескольких каналах, приходит один раз.

Как выглядит сообщение:

```
🧪 Провести тестирование сайта на планшете и смартфоне
📍 FL.ru · 💰 2 000 ₽
Нужно проверить адаптивную вёрстку…
Открыть заказ →
```

## Как работает фильтр

- **Заголовок** содержит любое QA-слово (тестирование, тестировщик, QA, автотест, test case,
  Selenium, Playwright, Postman…), **или**
- **описание** содержит явный признак QA-заказа («нужен тестировщик», «провести тестирование»,
  «manual testing», «beta testers»…).
- Ложные «тесты» вырезаются: «тестовое задание», «тест-драйв», «A/B-тест», «тестовый период» и т.п.

Списки `KEYWORDS`, `STRONG` и `EXCLUDE` лежат в начале `bot.py`, их можно править.

## Шаг 1. Создать бота (2 минуты)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен**.
2. Откройте своего бота и нажмите **Start** (или напишите ему что угодно).
3. Скопируйте `.env.example` в `.env` и впишите токен.
4. Узнайте свой chat_id:
   ```
   python bot.py --get-chat-id
   ```
   Впишите число в `.env` как `TELEGRAM_CHAT_ID`.
5. Проверка без отправки: `python bot.py --dry-run`

## Шаг 2. Запуск 24/7

### Вариант А (рекомендуется, бесплатно): GitHub Actions

Компьютер может быть выключен, проверка идёт на серверах GitHub каждые ~10 минут.

1. Создайте на GitHub **новый публичный** репозиторий (например `qa-freelance-bot`).
   Для публичных репозиториев минуты Actions бесплатны без лимита; в приватном
   бесплатных 2000 минут в месяц на запуск каждые 10 минут не хватит.
   Секреты остаются скрытыми и в публичном репозитории.
2. Залейте туда содержимое этой папки (`.env` не попадёт, он в `.gitignore`).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. **Actions** → включите workflows → «QA freelance monitor» → **Run workflow**, чтобы проверить.

Дальше всё работает само. Уже отправленные заказы запоминаются в `seen.json`,
бот коммитит его после каждого запуска (поэтому GitHub не отключит расписание за неактивность).

### Вариант Б: свой компьютер или VPS

```
python bot.py --loop
```

или двойной клик по `run_bot.bat`. Интервал задаётся в `.env` (`CHECK_INTERVAL`, по умолчанию 300 секунд).
Работает только пока компьютер включён. На VPS запускайте через `systemd`, `screen` или `tmux`.

## Команды

| Команда | Что делает |
|---|---|
| `python bot.py` | один проход: найти новые заказы и отправить |
| `python bot.py --loop` | бесконечный цикл |
| `python bot.py --dry-run` | показать найденное в консоли, ничего не слать |
| `python bot.py --mark-seen` | считать всё текущее просмотренным (чтобы не получить пачку старых заказов) |
| `python bot.py --get-chat-id` | показать chat_id |

Зависимостей нет, нужен только Python 3.9+.
