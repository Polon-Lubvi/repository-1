# План тестирования: бот вакансий для графического дизайнера

## Область
**Входит:** сбор вакансий, фильтры и оценка, тексты (шаблон и Claude с откатом на шаблон),
Excel-выгрузка, обучение по присланному файлу, команды бота, доступ, расписание, запуск
`run_bot.bat`, перенос на другой Windows-компьютер, автопуш на GitHub.
**Не входит:** живая переписка в Telegram-клиенте (проверяется вручную, чек-лист ниже), качество
писем Claude (нет ключа).

## Критерии выхода
Все P0 пройдены, P1 ≥ 90 %, нет открытых критичных багов.

## Риски
| Риск | Вероятность | Влияние | Что делаем |
|---|---|---|---|
| Сайт поменял вёрстку → 0 вакансий | средняя | среднее | живой смоук по каждому источнику, в логе «найдено 0» |
| Личные данные утекают в публичный GitHub | низкая | высокое | проверка утечек в sync-скрипте (TC-17) |
| Два экземпляра бота с одним токеном | средняя | высокое | инструкция переноса: сначала остановить у себя |
| На чужом ПК нет Python / путь с кириллицей | средняя | высокое | симуляция переноса в новую папку (TC-14) |

## Ручной чек-лист в Telegram (после запуска на целевом ПК)
1. `/start` → приходит справка со временем выгрузки.
2. `/id` → показывает ID.
3. `/now` → «Собираю…», через 2–4 мин приходит .xlsx с подписью «Лучшие: …».
4. Вписать письмо в жёлтую колонку, отправить файл → «Учла писем: 1».
5. `/stats` → «Ваших писем для обучения: 1».
6. `/addsite @designhunters` → «Уже был в списке — включила».
7. `/settime 17:00` → «Готово: выгрузка каждый день в 17:00».
8. С чужого аккаунта (если задан ALLOWED_USER_IDS) → «Этот бот приватный».
