КАК ЗАПУСТИТЬ БОТА ВАКАНСИЙ НА СВОЁМ КОМПЬЮТЕРЕ
================================================

1. УСТАНОВИТЬ PYTHON (один раз)
   - Откройте https://www.python.org/downloads/ и нажмите "Download Python".
   - Если открылось окно с галочками: ОБЯЗАТЕЛЬНО отметьте
     "Add python.exe to PATH", затем нажмите "Install Now".
   - Если открылась чёрная консоль "Python installation manager" с вопросами:
       * "Windows is not configured to allow paths longer than 260..." -> N, Enter
       * вопрос про установку текущей версии CPython -> y, Enter
       * вопрос про добавление в PATH -> y, Enter
       * остальные вопросы -> просто Enter
   - Проверка: Win+R -> cmd -> Enter -> введите  python --version
     Должно показать "Python 3.1x.x".

2. РАСПАКОВАТЬ ЭТОТ АРХИВ
   - Если архив скачан из интернета: правой кнопкой по архиву -> Свойства ->
     галочка "Разблокировать" -> ОК.
   - Правой кнопкой -> "Извлечь всё" в постоянное место,
     например "Документы\Бот вакансий" (не в "Загрузки").

3. ЗАПУСТИТЬ
   - Дважды щёлкните run_bot.bat.
   - Если появится "Система Windows защитила ваш компьютер":
     "Подробнее" -> "Выполнить в любом случае".
   - Первый запуск 2-5 минут (устанавливаются пакеты).
   - Должна появиться строка "[3/3] Bot is running".
     ОКНО НЕ ЗАКРЫВАТЬ (свернуть можно).

4. TELEGRAM
   - Откройте бота в Telegram (ссылку пришлёт тот, кто его настраивал) и нажмите Start.
   - Отправьте /id и запишите "Ваш ID".
   - Откройте файл .env Блокнотом (правой кнопкой -> Открыть с помощью -> Блокнот)
     и впишите свой ID:  ALLOWED_USER_IDS=ваш_ID
     Так бот не будет отвечать посторонним (в письмах ваши контакты!).
     Сохраните, закройте окно бота и снова запустите run_bot.bat.
   - Отправьте /now — через 2-4 минуты придёт Excel с вакансиями.

5. ЧТОБЫ БОТ РАБОТАЛ КАЖДЫЙ ДЕНЬ
   - Автозапуск: правой кнопкой по run_bot.bat -> "Создать ярлык".
     Win+R -> введите shell:startup -> Enter -> перенесите ярлык в открывшуюся папку.
   - Спящий режим: Параметры -> Система -> Питание -> "Переводить в спящий режим" -> "Никогда".
   - Выгрузка приходит в 17:00. Если компьютер в это время спал и проснулся до 23:00 —
     выгрузка придёт сразу после пробуждения. Если бот запущен позже 17:00, а сегодняшней
     выгрузки ещё не было, она придёт через минуту после запуска.

6. КАК ПОЛЬЗОВАТЬСЯ
   - В Excel впишите свой вариант письма в жёлтую колонку, сохраните и отправьте файл боту —
     следующие письма будут в вашем стиле.
   - /now — выгрузка сейчас, /sites — сайты, /addsite ссылка — добавить сайт,
     /settime 18:00 — другое время, /stats — статистика, /stop — отписаться.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
   - Окно бота не закрывается при ошибке — сфотографируйте его и отправьте тому,
     кто настраивал бота.
   - "Conflict" в окне = бот запущен ещё где-то (на другом компьютере). Его нужно там закрыть.
