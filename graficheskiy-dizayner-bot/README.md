# Бот вакансий для графического дизайнера

Telegram-бот: каждый день в 17:00 (МСК) присылает в чат Excel со свежими вакансиями под резюме
соискателя (графический дизайнер, Ростов-на-Дону, удалённо/гибрид) и учится на её исправленных письмах.

> Личные данные соискателя (имя, контакты, портфолио, резюме) хранятся в `bot/candidate_private.py`
> и в git не попадают. Для нового человека скопируйте `bot/candidate_private.example.py`
> в `bot/candidate_private.py` и заполните.

## Что в Excel

| Колонка | Что там |
|---|---|
| №, Дата, Источник, Вакансия, Компания, Зарплата, Формат / город | основные данные |
| Подходит, из 10 | оценка совпадения с интересами (зелёный ≥ 7, жёлтый ≥ 5) |
| Кратко о вакансии | 2–3 предложения о компании, задачах и условиях |
| Чем интересна | почему вакансия подходит, с опорой на её опыт; строки с ⚠ — минусы |
| Ссылка | кликабельная ссылка на вакансию |
| Сопроводительное письмо (черновик бота) | готовое письмо — предпоследняя колонка |
| **Моё сопроводительное письмо** | пустая жёлтая колонка — сюда вписывается свой вариант |

Пример выгрузки (`пример_выгрузки.xlsx`) лежит только в локальной папке: в письмах есть контакты соискателя.

## Самообучение

1. Впишите свой вариант письма в жёлтую колонку (достаточно 1–3 строк).
2. Сохраните файл и отправьте его боту.
3. Бот сохранит пары «черновик → ваш вариант» и:
   - в режиме Claude: подставляет самые похожие ваши письма как образцы и ведёт «памятку стиля»
     (что вы меняете, что убираете); её видно в `/stats`;
   - в режиме шаблонов: берёт ваше самое похожее письмо за основу и подставляет новую вакансию;
   - в обоих режимах поднимает выше вакансии, похожие на те, для которых вы писали письма.

## Источники

Из файла заказчика: hh.ru, Зарплата.ру, hirify, remote-job, careerspace, SuperJob, Карьерист и
6 Telegram-каналов (forgamedev, fordesigner, designer_ru, vdhl_good, digital_rabota, Ludivkulture).

Добавлены дополнительно: Хабр Карьера, Работа России (trudvsem, открытый API), designer.ru,
Telegram-каналы designhunters, workindesign, designer_vacancy, designvacancy, vakansiidesign.

Управление из бота:

- `/sites` — список с номерами
- `/addsite https://t.me/канал` или `/addsite @канал` — Telegram-канал
- `/addsite https://сайт.ру/vacancies Название` — любой сайт. Для известных площадок свой разборщик,
  для остальных бот ищет на странице ссылки с «дизайнерскими» словами и читает их. Сразу после
  добавления бот пробует собрать вакансии и показывает, что нашёл.
- `/removesite 5`, `/enablesite 5` — выключить или включить сайт

Ограничения: у careerspace API закрыт доступом, а robots.txt запрещает ботам `/api` и адреса
с `?`. Поэтому бот читает только публичные страницы: ленту `/jobs` и подборки (`/collection/remote`,
`junior`, `brand_marketing`, `motion_design`, `ux_ui` и др., по ~10 свежих вакансий в каждой).
Дизайнерских вакансий оттуда немного, обычно 1–3 в день. Список подборок — `CAREERSPACE_PAGES`
в `bot/sources.py`. Сайты могут менять вёрстку: если источник перестал давать вакансии, это видно
в логе (`найдено 0`).

## Фильтры (файл `bot/candidate.py`)

- Только дизайнерские должности. Исключаются маркетплейсы и карточки товаров, UX/UI, интерьер,
  3D/моушн, геймдизайн и т.п.
- Формат: удалённо из любого города, или гибрид/офис в Ростове-на-Дону. Офис в другом городе отсекается.
- Выше в списке: айдентика, брендинг и упаковка, вёрстка, коммуникационный дизайн, digital,
  образовательные и культурные проекты, зарплата от 60 000 ₽.
- Ниже: senior/lead, опыт от 4 лет, маркетплейсы в описании, веб-дизайн без брендинга.
- Вакансии за последние 7 дней (`FRESH_DAYS`); то, что уже отправлялось, не повторяется.

## Установка (Windows)

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Дважды кликните `run_bot.bat`. В первый раз он создаст `.env` и откроет его в Блокноте —
   вставьте токен в `TELEGRAM_BOT_TOKEN=`, сохраните и снова запустите `run_bot.bat`.
3. Напишите боту `/start` — этот чат начнёт получать выгрузку. `/now` — получить выгрузку сразу.
4. Желательно: впишите свой Telegram ID (`/id`) в `ALLOWED_USER_IDS`, чтобы бот не отвечал посторонним.
5. Для писем от ИИ: впишите `ANTHROPIC_API_KEY` (ключ с console.anthropic.com). Модель —
   `CLAUDE_MODEL`, по умолчанию `claude-opus-5-5`. Без ключа работают шаблоны.

Бот присылает выгрузку, только пока он запущен. Для работы без включённого компьютера
запустите его на любом VPS (Linux):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # и заполните
nohup .venv/bin/python -m bot.main > bot.log 2>&1 &
```

## Ручной прогон без Telegram

```bash
.venv\Scripts\python -X utf8 -m bot.run_once
```

Соберёт Excel в `data/reports/` и покажет статистику по каждому источнику (уже отправленным
вакансии не помечаются). Обучение по файлу: `python -m bot.run_once --learn файл.xlsx`.

## Структура

```
bot/
  main.py        Telegram-бот, расписание, команды
  pipeline.py    сбор → фильтр → оценка → тексты → Excel; обучение по файлу
  sources.py     разборщики сайтов и Telegram-каналов
  scoring.py     оценка 0–10 и причины
  letters.py     краткое описание, «чем интересна», письмо (Claude или шаблон)
  excel_io.py    создание выгрузки и чтение присланного файла
  candidate.py   резюме, интересы, стоп-слова
  storage.py     SQLite (data/bot.sqlite3): сайты, отправленное, примеры писем
config/sites.json  стартовый список сайтов
```

В `data/` лежат база, выгрузки и присланные файлы; эта папка в git не попадает.

## Бэкап на GitHub

`tools/sync_to_github.sh` копирует проект в `_github-backup/graficheskiy-dizayner-bot`
(без `.venv`, `data/`, `.env`, `bot/candidate_private.py` и примера выгрузки), проверяет копию
на контакты соискателя и, если есть изменения, коммитит и пушит. В Claude Code он запускается
автоматически Stop-хуком из `.claude/settings.local.json` после каждого ответа. Вручную:
`bash tools/sync_to_github.sh`.
