# Аврора-ГБО — сайт сервиса в Самаре

Одностраничник для сервиса **АврораАвтоРемонт** (вывеска на логотипе —
«Аврора-ГБО»), Самара, ул. Авроры, 150Г. Сделан из шаблона
[Shablon_CentrGBO](../Shablon_CentrGBO): чистая статика, никакого npm и
сборки, файлы открываются как есть.

Правила правки файлов, работа с фотографиями и список того, чего делать
нельзя, — в [TEMPLATE-README.md](TEMPLATE-README.md), он достался от
шаблона и остаётся в силе.

## Как посмотреть

Двойной клик по `Запустить сайт (Windows).bat` — откроется
http://localhost:8080 . Или вручную:

```bash
cd Site_CentrGBO_New/site && python -m http.server 8912
```

Порт лучше каждый раз новый — браузер жёстко кэширует старую версию.

## Что изменено против шаблона

- **Тема** — белый фон, зелёные надписи. Зелёный взят из логотипа
  (`#40ab6d`) и разведён по светлоте, чтобы мелкий текст держал контраст
  4,5:1. Весь цвет — в `site/theme.css`.
- **Логотип** — `site/img/logo.png`, вырезан кругом из присланного
  скриншота. Из него же `favicon.ico` и `favicon.png`.
- **Карта** — `site/img/map.jpg`, собрана из тайлов OpenStreetMap вокруг
  ул. Авроры, 150Г, с меткой. Атрибуция OSM стоит в подвале.
- **Время в пути** — блок «Сколько ехать из районов города», девять
  районов Самары. Время и расстояние посчитаны по автомобильному
  маршруту (OSRM) от опорной точки района, **без пробок**. Каждая строка
  открывает маршрут в Яндекс.Картах.
- **Подвал** переписан: ряд контактов (телефон, WhatsApp, Viber,
  Яндекс.Карты), адрес, график по дням, ссылки на карточку / отзывы /
  прайс / маршрут, список услуг, дисклеймер про цены.
- **Счётчик установок** на первом экране убран — цифра была выдуманной.
  На его месте реальный рейтинг 4,3 с числом оценок.
- **Калькулятор** в шаблоне отсутствует. В соседнем
  [Site_CentrGBO_SPb](../Site_CentrGBO_SPb) он есть — если нужен здесь,
  переносить оттуда (`app.js` там новее на ~100 строк).

## Что нужно от клиента перед публикацией

1. **Фотографии** — в вёрстке 18 плашек с подписью, какой кадр нужен.
   Класть в `site/img/`, прописывать `src` в `site/content.js`.
2. **Сроки гарантии** на работы. В карточке «Гарантия» указана без
   сроков, поэтому в блоке гарантии стоит обтекаемое «срок подтверждает
   мастер».
3. **Реквизиты** — ОГРНИП / ИНН / ОКПО для подвала (`legal` в
   `site/config.js`), сейчас пустые и не выводятся.
4. **Имена мастеров** и стаж — четыре карточки в блоке 6 пустые.
5. **Подтвердить цену 20 000 ₽.** Яндекс помечает прайс как давно не
   обновлявшийся; на сайте про это честно написано, но лучше обновить.
6. **Проверить продающие формулировки.** В `site/content.js` они помечены
   комментарием `СОГЛАСОВАТЬ` — это обычные для автосервиса обещания,
   которых в карточке нет.
7. **Ссылка на политику конфиденциальности** — из подвала убрана, потому
   что вела в никуда. Появится документ — вернуть.
